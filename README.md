# blogscapes
A placeholder for functions related to the blogging workflow. 

## Note

This is just a prototype to be discussed with the team. 

If decision is to continue blog workflow function development here is good, if not
functions could be easily exported to `kyber`

## Justification to create a new package:

My impression is that Kyber is a github-cohort-lifecycle manager. The blogs workflows are different.

Having a single package for blogs workflows can give us the chance to expand functionality or 
implement more ideas to what it is an essential part of openscapes: communicating
